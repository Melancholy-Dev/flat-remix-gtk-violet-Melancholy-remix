# More information at [drasite.com/flat-remix-gtk](https://drasite.com/flat-remix-gtk)

A dark purple variant of the Flat Remix GTK theme modified by me. Using this theme daily on Linux Mint Cinnamon, not tested with other DE (such as GNOME)

# How to use and install

1) Download the codebase as a ZIP from GitHub
2) Extract the compressed file on `$HOME/.themes/` or on `/usr/share/themes/`. If the first option is used, you may want to create a link so that root apps can use the theme:
```
sudo ln -sfn "$HOME/.themes/Flat-Remix-GTK-Violet-Dark" /usr/share/themes/Flat-Remix-GTK-Violet-Dark
```
3) If you use the theme on Cinnamon as intended, open settings -> Themes, and apply it on applications and Desktop
4) Enjoy!
